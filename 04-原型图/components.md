# 组件规范

所有组件在 `mock.css` 中已有对应实现，前端实现（Element Plus + 自定义样式）须 1:1 复刻。

## 按钮 Button

| 类型 | 高度 | 内边距 | 边框 | 文字 | 用途 |
|---|---|---|---|---|---|
| 主按钮 `.btn.primary` | 32 | 0 14 | `#15344A` | #fff | 提交、保存、确认 |
| 次按钮 `.btn` | 32 | 0 14 | `#DCE5E9` | `#1C2B33` | 取消、重置、导出 |
| 描边 `.btn.ghost` | 32 | 0 14 | `#237A8B` | `#237A8B` | 次级主动作 |
| 危险 `.btn.danger` | 32 | 0 14 | `#B03035` | `#B03035` | 删除、驳回、作废 |
| 小号 `.btn.sm` | 26 | 0 10 | — | 12px | 表格行内 |
| 文字 `.btn.link` | auto | 0 4 | 无 | `#2D5B6B` | 查看详情 |

- 圆角 6px，字号 13px，禁用态 opacity .5 + cursor not-allowed。
- 同一行主按钮不超过 1 个。

## 表单 Form

- 标签在左，宽 100–120px，右对齐，必填项前加红色 `*`。
- 输入框高 34px，边框 `#DCE5E9`，聚焦边框变 `#237A8B`，无外发光。
- 校验：失焦即时校验 + 提交整表校验；错误文案红色 12px，位于控件下方。
- 下拉框宽 180–240px（`.select` 默认 200px）。
- 长表单分「基础信息 / 业务信息 / 附件」三段，段间 24px。
- 关闭前检测未保存内容（`isDirty`），弹二次确认。

## 表格 Table

- 表头背景 `#F7FAFB`，文字 `#5A6B74` 500 字重，下边框 `#DCE5E9`。
- 行高 44px（含内边距 11px），行悬停 `#FAFCFD`，行分隔线 `#EDF2F4`。
- 表头不设固定宽度：`min-width` + 内容自适应，超宽横向滚动。
- 编号 / 状态 / 日期 / 操作列 `white-space: nowrap`。
- 状态列用 `.tag`，操作列「查看 + 2 操作 + 更多」。

## 标签 Tag

高 22px，左右内边距 8px，圆角 4px，字号 12px，1px 同色系边框 + 浅底。
五色：blue / green / orange / red / gray，对应 `design-system.md` 第 7 节状态映射。

## 卡片 Card / Panel

- 白底，1px `#DCE5E9` 边框，圆角 8px，内边距 18–20px，无阴影。
- 卡片头：标题 15px/600 + 副说明 12px `#8C9AA3` + 右侧操作区。

## 指标 Metric

- 键 12px `#5A6B74`；值 24px/600 `#15344A` 等宽数字；脚注 11.5px `#8C9AA3`。
- 看板 6 个指标一行（`g6`），1440 宽下每个约 210px。

## 弹窗 Modal

宽 520px，圆角 8px，头/体/脚三段，头 16px/600，脚右对齐按钮组，遮罩 `rgba(21,52,74,.34)`。

## 抽屉 Drawer

右侧滑出，宽 520px（审批类 640px），带 `0 6px 24px rgba(21,52,74,.12)` 阴影，头部固定「单号 + 状态 + 操作人」，底部固定操作条。

## 分页 Pager

右对齐，页码按钮 28×28，圆角 4px，当前页主色底白字；左侧显示「共 N 条」。

## 时间轴 Timeline

左竖线 1px `#DCE5E9`，节点圆点 7px `#237A8B` + 3px 浅色外环，时间 12px 等宽 `#8C9AA3`，事件正文 13px。

## 状态标签组件（前端统一封装）

`<StatusTag :status="row.status" />`，内部维护 9 种预约状态 → 色/文案映射，禁止各页面自行写 if-else。

## 时间格式化（前端统一封装）

`formatTime(v)` → `YYYY-MM-DD HH:mm:ss`；`formatDate(v)` → `YYYY-MM-DD`；空值返回 `-`。
全系统所有表格、详情、时间轴统一调用，禁止各页面自己拼字符串。
