# 设计系统 · 体检预约与报告领取管理系统

严格取自需求文档「UI 视觉与交互设计」一节，全站唯一色彩与栅格来源。

## 1. 视觉定位

「公共服务蓝」专业业务系统。强调数据可读性与状态辨识，不使用巨幅口号、装饰光效、悬浮球、大插画。
阴影只出现在抽屉与弹窗；卡片圆角 6–8px；数字列启用 tabular-nums 等宽数字。

## 2. 色彩令牌

| 令牌 | 色值 | 用途 |
|---|---|---|
| `--primary` | `#15344A` | 顶栏、左侧菜单底、主按钮、关键数字 |
| `--secondary` | `#237A8B` | 次级按钮、筛选选中态、普通图表系列、当前菜单 |
| `--bg` | `#F3F7F8` | 主内容区背景 |
| `--accent` | `#2D5B6B` | 链接、信息提示、图表对比系列 |
| `--success` | `#2D7A58` | 已完成 / 已通过 / 正常 |
| `--danger` | `#B03035` | 驳回、超时、异常、删除确认（小面积） |
| `--warn` | `#B4761F` | 待处理、即将超时（派生色） |
| `--text` | `#1C2B33` | 正文 |
| `--text-2` | `#5A6B74` | 次要说明、表头 |
| `--text-3` | `#8C9AA3` | 占位、辅助时间 |
| `--line` | `#DCE5E9` | 边框、分割线 |

状态不得只靠颜色：每个色标签必须同时带中文文案（见 `状态色映射`）。

## 3. 字体阶梯

| 层级 | 字号 / 行高 | 字重 | 场景 |
|---|---|---|---|
| H1 页面标题 | 18 / 26 | 600 | 内容区首行 |
| H2 面板标题 | 15 / 22 | 600 | 卡片头 |
| 正文 | 14 / 21.7 | 400 | 表格、表单、说明 |
| 辅助 | 12.5 / 19 | 400 | 表单标签、指标说明 |
| 微型 | 11.5 | 400 | 时间戳、脚注 |

字体族：`-apple-system, "PingFang SC", "Microsoft YaHei", sans-serif`；数字：`"SF Mono", ui-monospace` + `font-variant-numeric: tabular-nums`。

## 4. 栅格与间距

- 桌面端：左菜单 220px + 顶栏 56px + 自适应内容区；内容区内边距 24px。
- 间距基数 4px，常用 8 / 12 / 16 / 20 / 24。
- 卡片间距 16px；表单行间距 16px；表格单元格内边距 10–12px。
- 表单标签宽 100–120px；单列输入 360–520px；搜索下拉 180–240px。
- 看板按 1440×900 一屏设计，不使用纵向滚动。

## 5. 圆角 / 阴影

- `--r: 6px`：按钮、输入框、标签、小卡片
- `--r-lg: 8px`：面板、弹窗、抽屉
- 阴影仅两处：抽屉 `0 6px 24px rgba(21,52,74,.12)`；弹窗同值

## 6. 双端风格区分

| 角色 | 框架 | 识别特征 |
|---|---|---|
| 体检用户 | 门户：64px 白色顶栏 + 横向导航 + 1180px 居中内容 | 浅色、卡片流、套餐封面 |
| 企业联络员 | 管理框架，但菜单仅「团检批次 / 名单导入 / 集合统计」 | 侧栏顶部标「企业联络员」 |
| 前台工作人员 | 管理框架，深色侧栏 + 工作台优先 | 到检台整页操作区 |
| 体检管理员 | 管理框架，完整菜单（看板/主数据/业务/系统） | 深蓝侧栏 + 6 指标看板 |

| 待确认 | gray | 待确认 |
| 待缴费 | orange | 待缴费 |
| 待到检 | blue | 待到检 |
| 体检中 | blue | 体检中 |

报告版本 / 领取方式：本人下载=blue、现场领取=green、委托代领=orange。

## 8. 交互规范

- 危险操作红色描边按钮 + 二次确认；普通取消不用强提醒。
- 审批/流转用右侧抽屉，抽屉内同时展示单据摘要。
- 加载 >300ms 显示骨架或表格 loading，禁止整页白屏。
- 空状态说明原因 + 下一步（如「当前筛选无记录，清空筛选或新建预约」）。
- 行内最多「查看 + 2 个高频操作」，其余收进「更多」。
- 低于 768px：侧栏转抽屉，表格转信息卡片，点击区 ≥44px。
